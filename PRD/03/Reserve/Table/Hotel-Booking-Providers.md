# مستندات جدول `hotel_booking_providers`

## توضیحات

این جدول مشخص می‌کند که برای هر هتل چه ارائه‌دهندگان (Providers) رزروی در دسترس هستند، ترتیب اولویت آن‌ها چیست و آیا فعال هستند یا خیر.
زمانی که موتور رزرواسیون نیاز به رزرو اتاق برای یک هتل خاص دارد، از این جدول کوئری می‌گیرد (مرتب‌شده بر اساس `priority ASC`) تا ارائه‌دهندگان فعال را به ترتیب برای رزرو امتحان کند.

## تصمیمات طراحی

- یک **قید یکتا (unique constraint)** روی `(hotel_id, provider_id)` از ایجاد رکوردهای تکراری جلوگیری می‌کند.
- برای `priority` (اولویت) از قانون **مقدار کمتر = اولویت بیشتر** استفاده شده است (مقدار `0` ابتدا امتحان می‌شود).
- مقدار `is_active = false` یک مسیر رزرو را بدون حذف کردن آن غیرفعال می‌کند.
- قانون `onDelete('cascade')` روی `hotel_id` به این معناست که با حذف یک هتل، تمام ارائه‌دهندگان متصل به آن نیز خودکار حذف می‌شوند.
- قانون `onDelete('cascade')` روی `provider_id` به این معناست که با حذف یک ارائه‌دهنده، تمام اتصالات آن به هتل‌ها پاکسازی می‌شود.

## ستون‌ها

| نام ستون      | نوع (Type)       |
| ------------- | ---------------- |
| `id`          | bigint unsigned  |
| `hotel_id`    | bigint unsigned  |
| `provider_id` | bigint unsigned  |
| `priority`    | tinyint unsigned |
| `is_active`   | tinyint(1)       |
| `created_at`  | timestamp        |
| `updated_at`  | timestamp        |


| رابطه                     | جدول        | ستون کلید خارجی |
| ------------------------- | ----------- | --------------- |
| متعلق است به (belongs to) | `hotels`    | `hotel_id`      |
| متعلق است به (belongs to) | `providers` | `provider_id`   |
